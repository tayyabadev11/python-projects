# Client Data Management System
A Python-based application for managing client records, searching data, generating reports, exporting CSV files, creating backups, and maintaining application logs.
## Features
- Add and view client records
- Search clients by name, email, or service
- Email validation
- JSON data storage
- CSV report generation
- Performance reports
- Automatic data backup
- Application logging
- Error handling
## Technologies Used
- Python
- JSON
- CSV
- Regular Expressions
- path lib
- OS
- shut il
- collections
- datetime
- logging
## How to Run
Run the following file in Python:
`project12_client_data_management_system.py`
Follow the menu options displayed in the terminal.
