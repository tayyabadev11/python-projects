# Project 11 - Student Records & Performance Analyzer
A Python-based application for managing student records and analyzing academic performance.
## Features
- Add and manage student records
- View stored records
- Search student records
- Calculate grades and results
- Analyze student performance
- Store data in JSON format
- Export data to CSV format
- Date and time tracking
- File and folder management
- Exception handling
- Performance statistics
## Technologies Used
- Python
- JSON
- CSV
- OS Module
- Date & Time
- Functions
- Exception Handling
## Project Overview
This project is a menu-driven Python application designed to manage student information and analyze academic performance.
It allows users to add, view, search, and analyze records while keeping the data organized through JSON and CSV file storage.
## Learning Objectives
This project combines multiple Python concepts into one practical application, including:
- Functions and parameters
- File handling
- JSON data
- Exception handling
- Date and time
- OS module
- Data processing
- Problem solving
## How to Run
1. Open the project in Visual Studio Code.
2. Run `project11_student_records_performance_analyzer.py`.
3. Follow the menu options displayed in the terminal.
4. Add and analyze student records.
