# Inventory & Sales Management System
A Python-based system for managing products, inventory, sales transactions, and reports.
## Features
- View inventory
- Add new products
- Search products
- Record sales
- Sales summary
- Generate CSV reports
- Low-stock report
- JSON data storage
## Technologies Used
- Python
- JSON
- CSV
- File Handling
- Logging
- Datetime
## Project Purpose
This project demonstrates how Python can be used to manage inventory, process sales, track stock, and generate structured reports.
